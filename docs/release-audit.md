# Publication audit

The public candidate is a fresh repository containing generalized source,
synthetic examples, tests, CI and technical documentation. The earlier
personal installation and its operational history are retained separately.
No private plists, SSH config, keys, credentials, logs, application names,
internal host aliases, private network addresses or personal filesystem paths
are imported into this repository or its history.

Review covers tracked paths/content, all reachable commit blobs, commit
metadata, remotes and release asset source bytes. Expected public account
identity in Git metadata and the GitHub remote is intentional. Loopback
addresses, reserved example.invalid and the illustrative dev-server alias
are deliberate public examples. Automated scans supplement a manual read;
no scan can prove absence of every possible secret.

License selection remains outstanding. Keep this candidate private and its
release in draft until the owner selects a license and the corresponding
LICENSE/README/release wording is updated and audited again. Do not import
private operational recovery records as part of publication.
